## [3.1.0] - 2026-11-13

### Changes

- add repeating sound while crafting
- add jei recipe and usages lookup from gui
- add option to remove the shift-tooltip
- render items and blocks in tooltips
- add queue removal
- add note about v3 to the README.md
- hold shift to add 64 entries to queue
- document new GroovyScript methods
- add option to keep GUI open when queue is empty
- display msg when no recipes available
- remove HEI hard dep
- add hideInvalid() modifier for crafting GUIs

### Bugfixes

- queue issues

### Miscellaneous

- java doc formatting
- reformat with prince-of-space
- apply buildscript
- cleanup
- update class header
